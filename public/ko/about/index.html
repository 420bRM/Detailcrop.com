About

디테일크롭은

사진 한 장에서 필요한 부분을 여러 군데 잘라 내는 도구입니다. 그걸 사진 수십 장에 한 번에 합니다.

옷 사진이 20장 있고 장마다 원단, 단추, 로고, 밑단 확대컷이 필요하다면 잘라야 할 컷은 80개입니다. 확대할 위치가 사진마다 달라서 같은 자리를 한꺼번에 자르는 일괄 크롭으로는 안 되고, 편집기로 한 장씩 자르다 보면 중간에 비율이나 파일 이름이 한두 번은 꼭 틀어집니다.

디테일크롭에서는 사진마다 상자만 옮겨 놓으면 됩니다. 비율, 출력 크기, 파일 이름은 처음에 한 번 정해 두면 모든 컷에 똑같이 들어가고, 다 끝나면 80장이 zip 하나로 내려옵니다. 이 방식을 멀티크롭이라고 부릅니다.

주요 기능

  • 사진 한 장에 상자 최대 6개
  • 한 번에 200장까지 (JPEG, PNG, WebP, AVIF, GIF)
  • 작업 전체에 같은 비율 고정, 필요하면 컷마다 다른 비율
  • 기울어진 사진 수평 맞추기
  • 인스타그램 피드 3·6·9분할
  • WebP·JPEG·PNG 저장, 파일 이름 자동 지정

순서대로 따라 하는 방법은 사용법에, 실제 작업 예시는 활용 예시에 있습니다.

사진은 서버로 올라가지 않습니다

자르는 작업은 전부 지금 쓰고 계신 브라우저 안에서 처리됩니다. 사진을 서버로 보내는 코드가 아예 없어서, 출시 전 제품 사진이나 고객이 보낸 원본도 걱정 없이 쓰셔도 됩니다.

어떤 설정을 많이 쓰는지 보려고 이미지 크기, 장수, 고른 설정 정도는 익명으로 기록합니다. 사진 자체는 기록하지 않고, 이 기록도 도구 화면 맨 아래에서 끌 수 있습니다.

자주 묻는 질문

무료인가요?

네, 무료입니다. 가입이나 설치도 필요 없습니다.

화질이 떨어지지 않나요?

기본 설정은 원본 픽셀을 그대로 잘라 내기 때문에 화질이 떨어지지 않습니다. 다만 출력 크기를 고정해 두고 그보다 작게 상자를 잡으면 사진이 늘어나면서 흐려집니다. 그럴 때는 화면에 경고가 뜹니다.

휴대폰에서도 되나요?

열리기는 합니다. 하지만 상자 여러 개를 옮기고 크기를 맞추는 작업이라 PC가 훨씬 편합니다.

영상도 자를 수 있나요?

네. 영상 도구(베타)에서 같은 방식으로 영상에 상자를 여러 개 올리면 컷마다 mp4 파일로 저장됩니다.
