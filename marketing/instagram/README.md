# DetailCrop 인스타그램: 고정 게시물 3개 (캐러셀)

게시물 하나에 이미지 9장을 넣어 넘겨 보게 하고, 한국어·영어·일본어 3개를 프로필 상단에 고정합니다.

| 폴더 | 게시물 | 게시글 |
|---|---|---|
| `ko/01.jpg` … `09.jpg` | 한국어 캐러셀 | 아래 **한국어** |
| `en/01.jpg` … `09.jpg` | 영어 캐러셀 | 아래 **English** |
| `ja/01.jpg` … `09.jpg` | 일본어 캐러셀 | 아래 **日本語** |

모두 1080×1350(4:5). 한 게시물 안에서는 **01부터 09까지 순서대로** 넣습니다.
01번이 표지이고, 오른쪽 위에 언어 표시가, 오른쪽 아래에 "넘겨서 보기 →"가 들어 있어서
고정된 세 표지가 나란히 있어도 어느 언어인지 바로 보입니다.

## 올리고 고정하기

1. 새 게시물에서 여러 장 선택 → 01~09 순서로 고르기 → 비율은 **4:5 원본** 그대로.
2. 세 개를 다 올린 뒤 각 게시물의 `⋯` → **프로필에 고정**.
3. 고정 게시물은 **나중에 고정한 것이 왼쪽**에 옵니다. 한국어를 맨 왼쪽에 두려면
   일본어 → 영어 → 한국어 순서로 고정하세요.
   순서가 다르게 나오면 고정을 풀고 원하는 순서대로 다시 고정하면 됩니다.

`art-grid/`의 그림 9분할은 이 계획에는 쓰지 않습니다. 나중에 일반 게시물로 쓸 때를 위해 남겨 둡니다.
