# DetailCrop 인스타그램 첫 피드 9개

이미지는 모두 1080×1350(4:5), 같은 폴더의 `detailcrop-01.jpg` … `detailcrop-09.jpg`.
`profile-grid-preview.jpg`는 9개를 다 올렸을 때 프로필 격자가 어떻게 보이는지 보여줍니다.

## 올리는 순서

프로필은 **최신 글이 왼쪽 위**에 오기 때문에 **09 → 01 순서로** 올립니다.
그래야 첫 방문자가 격자 왼쪽 위에서 01(소개)부터 읽게 됩니다.
(툴의 피드 분할 기능과 같은 원리라서, 이것 자체가 07번 게시물의 좋은 예시이기도 합니다.)

| 올리는 순서 | 파일 | 주제 |
|---|---|---|
| 1번째 | 09 | 이런 분들께 + 사이트 안내 |
| 2번째 | 08 | 정렬 보정(회전·원근) |
| 3번째 | 07 | 인스타 피드 분할 |
| 4번째 | 06 | 업로드 없음(개인정보) |
| 5번째 | 05 | 사용법 3단계 |
| 6번째 | 04 | 일괄 처리·규격 통일 |
| 7번째 | 03 | 핵심 개념: 한 장에서 여섯 컷 |
| 8번째 | 02 | 왜 만들었나 |
| 9번째 | 01 | 브랜드 소개(고정 추천) |

01번은 올린 뒤 **프로필 상단 고정(Pin)** 해 두는 걸 추천합니다.

## 02 · 왜 만들었나

```

= 204번의 똑같은 크롭.

버튼 한 번에 전부 내보냅니다.

혹시 지금도 같은 크롭을 반복하고 계신가요? 🙋
```

## 03 · 한 장에 여섯 컷

```
일괄 크롭 도구는 많아요.
그런데 대부분 "한 장에 한 컷"이죠.

건물 꼭대기, 간판, 자동차, 사람…

상자 색과 번호가 미리보기와 1:1로 맞춰져 있어서
어떤 컷이 어디서 나왔는지 헷갈릴 일이 없어요.
```

## 04 · 여러 장을, 같은 규칙으로

```
확대컷은 한 장을 잘 자르는 일이 아니라
여러 장을 "똑같이" 자르는 일이에요.

✔️ 비율 고정 — 1:1, 4:5, 16:9, 직접 입력까지
✔️ 출력 크기 고정 — 모든 컷이 같은 픽셀로
✔️ 파일명 규칙 — {name}-{nn} 처럼 원본 이름 + 번호
✔️ 포맷 선택 — JPEG · PNG · WebP

설정 한 번이면 라인업 전체가 같은 규격으로,
zip 하나에 담겨 다운로드 폴더에 떨어집니다. 📦

🔗 detailcrop.com
```
