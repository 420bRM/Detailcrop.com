# 27개 게시 계획: 한국어 → 그림 9분할 → 영어

`full-grid-preview.jpg`는 27개를 모두 올린 뒤 프로필이 어떻게 보이는지 보여줍니다.
프로필은 최신 글이 위에 오므로, **맨 위가 영어, 가운데가 그림, 맨 아래가 한국어**가 됩니다.
한국어를 맨 위에 두고 싶다면 순서를 거꾸로(영어 → 그림 → 한국어) 올리면 됩니다.

## 올리는 순서

| 차례 | 파일 | 비고 |
|---|---|---|
| 1–9 | `detailcrop-09.jpg` → `detailcrop-01.jpg` | 한국어, 09부터 거꾸로. 문구는 `captions.md` |
| 10–18 | `art-post01.jpg` → `art-post09.jpg` | 그림 9분할, 파일명 번호 그대로. post01이 오른쪽 아래 조각 |
| 19–27 | `detailcrop-en-09.jpg` → `detailcrop-en-01.jpg` | 영어, 09부터 거꾸로. 문구는 `captions-en.md` |

**퍼즐이 깨지지 않는 조건:** 한 세트(9개)를 올리는 동안 중간에 다른 게시물을 끼워 넣지 않을 것.
각 세트가 정확히 3줄이라서 세트 사이는 줄이 맞습니다.
나중에 게시물을 1~2개 지우면 전체 격자가 한 칸씩 밀려 퍼즐이 깨지니, 지울 때는 3개 단위로 지우세요.

## 스팸처럼 보이지 않게 하려면

1. **하루에 27개를 한꺼번에 올리지 마세요.** 새 계정이 짧은 시간에 몰아서 올리면 인스타가 자동화(봇)로 의심해 일시적인 활동 제한을 걸거나 노출을 줄일 수 있습니다.
   - 추천: **하루에 한 세트(9개)씩, 사흘에 걸쳐** 올리고, 한 세트 안에서도 몇 분씩 간격을 두세요.
   - 더 안전하게 하려면 하루 3개(한 줄)씩 9일에 걸쳐 올려도 됩니다. 한 줄 단위로 올리면 격자는 계속 맞습니다.
2. **계정부터 사람처럼 채워 두세요.** 프로필 사진, 소개글, 링크를 먼저 넣고, 관련 계정 몇 곳을 팔로우하거나 댓글을 남긴 뒤에 게시를 시작하세요.
3. **해시태그를 모든 게시물에 똑같이 붙이지 마세요.** 똑같은 해시태그 묶음을 반복하면 스팸 신호가 됩니다. 문구마다 해시태그를 다르게 짜 두었으니 그대로 쓰면 됩니다. 한 게시물에 5~10개 정도면 충분합니다.
4. **한국어와 영어가 같은 내용이라는 점이 조금 걸립니다.** 프로필에서 같은 디자인이 두 번 반복돼 보이는데, 가운데 그림 퍼즐이 그 사이를 끊어 줘서 덜 어색합니다. 그래도 신경 쓰인다면 한 세트만 올리고, 게시글에 한국어와 영어를 함께 쓰는 방법도 있습니다.
5. 게시글 본문의 링크는 눌리지 않으므로 "프로필 링크"로 안내하는 방식 그대로 두면 됩니다.
